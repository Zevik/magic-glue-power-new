# הכוח הנעלם: מסע לעולם הגולות

אתר לימודי אינטראקטיבי, ללא שלב build וללא ספריות עיצוב חיצוניות. כל עמוד במסע הוא מודול נפרד עם כתובת משלו.

## קישורים לעמודים

הכתובת של כל עמוד היא `index.html#/<שם-עמוד>`:

| כתובת | עמוד |
|---|---|
| `#/start` | הכוח הנעלם (פתיחה) |
| `#/gravity` | הכוח המוכר |
| `#/invisible-force` | הכוח הנעלם |
| `#/microscope` | המיקרוסקופ המטורף |
| `#/dabkesem` | כוח הדבקסם |
| `#/air` | תעלומת האוויר |
| `#/heat` | ריקוד הגולות |
| `#/states` | מסיבת הגולות הגדולה |
| `#/puddle` | תעלומת השלולית שנעלמה |
| `#/tsuronim` | הכירו את הצורונים |
| `#/attraction` | משיכה בין צורונים |
| `#/mysteries` | פותרים את התעלומות |
| `#/reactions` | מהפכת הלגו (תגובות כימיות) |
| `#/smell` | איך האף שלנו יודע? |
| `#/summary` | השמות האמיתיים |

הניווט הוא לפי ה-hash, ולכן זה עובד בכל אחסון סטטי (כולל GitHub Pages) בלי הגדרות שרת,
וכפתורי "הקודם" ו"הבא" של הדפדפן עובדים.

## מבנה

```
index.html          מעטפת: הגופן, ה-CSS, פס ההתקדמות ומקום להרכבת העמודים
css/styles.css      מערכת העיצוב: צבעים, זכוכית, כפתורים, גולות ועולם צבעוני לכל עמוד
js/main.js          הראוטר: מרכיב עמוד לפי ה-hash ומנקה את הקודם
js/pages/*.js       עמוד לכל קובץ (ה-HTML וה-JS שלו)
js/pages/index.js   סדר העמודים
js/lib/             כלים משותפים (הקשר עמוד, גרירה, מולקולות, גולות זוהרות לקנבס)
```

### עמוד חדש

עמוד הוא מודול שמייצא:

```js
export const slug = 'my-page';          // הכתובת: #/my-page
export const title = 'כותרת';
export const sectionClass = 'theme-my-page'; // עולם הצבעים של העמוד (מוגדר ב-css/styles.css)
export const html = `...`;              // תוכן העמוד; קישורים: <a href="#/other-slug">
export function init(page) { ... }      // אופציונלי: מופעל כשהעמוד עולה
export const reinitOnResize = true;     // אופציונלי: init חוזר אחרי שינוי גודל מסך
```

לאחר מכן מוסיפים אותו ל-`js/pages/index.js` במקום הרצוי בסדר.

בתוך `init(page)` משתמשים ב-`page.frame(...)` לאנימציות, ב-`page.timeout(...)` לטיימרים
וב-`{ signal: page.signal }` להאזנות. הכול נעצר ומתנקה אוטומטית ביציאה מהעמוד.

## הרצה מקומית

המודולים של JavaScript לא נטענים מ-`file://`, לכן צריך שרת סטטי:

```bash
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000/`.
