# הכוח הנעלם: מסע לעולם הגולות

אתר לימודי אינטראקטיבי לילדים ולמבוגרים סקרנים. ללא שלב build וללא ספריות חיצוניות (רק גופנים של Google).
האתר פרוס ב-Vercel כאתר סטטי: כל push ל-`master` מעלה גרסה חדשה.

## מה יש בו

- **רקע חי** אחד שמצייר את "עולם הצבעים" של כל עמוד, ועובר בין העולמות בהחלקה (`js/lib/ambient.js`).
- **סאונד שנוצר בקוד** (Web Audio): קליקים, צלילי צלילה, רעם ותגובה לכל פעולה, עם מתג השתקה. אין קבצי שמע.
- **גולות זכוכית** מצוירות פעם אחת לספרייט (עומק, שבירת אור, השתקפות) וכל העמודים משתמשים בהן.
- **פיזיקה אמיתית** בעמודים: התנגשויות אלסטיות, קוהזיה בנוזל, קפיצים ושרשראות.
- **גילויים**: על כל פעולה משמעותית מקבלים "גילוי חדש", נשמר בדפדפן, ובסוף מקבלים תעודה להדפסה.
- **עומק למבוגרים**: בכל עמוד אזור "למבוגרים סקרנים" שנפתח בלחיצה, עם המדע המדויק.
- מקלדת: חיצים ימינה/שמאלה מעבירים עמוד. מותאם למובייל ול-`prefers-reduced-motion`.

## קישורים לעמודים

הכתובת של כל עמוד היא `index.html#/<שם-עמוד>`, והסדר נקבע ב-`js/pages/index.js`:

| כתובת | עמוד |
|---|---|
| `#/start` | הכוח הנעלם (פתיחה) |
| `#/gravity` | הכוח המוכר |
| `#/invisible-force` | הכוח הנעלם |
| `#/microscope` | המיקרוסקופ המטורף |
| `#/dabkesem` | כוח הדבקסם |
| `#/air` | תעלומת האוויר |
| `#/heat` | ריקוד הגולות |
| `#/states` | מסיבת הגולות הגדולה |
| `#/tsuronim` | הכירו את הצורונים |
| `#/attraction` | משיכה בין צורונים |
| `#/mysteries` | פותרים את התעלומות |
| `#/reactions` | מהפכת הלגו (תגובות כימיות) |
| `#/puddle` | תעלומת השלולית שנעלמה |
| `#/smell` | איך האף שלנו יודע? |
| `#/summary` | השמות האמיתיים |

הניווט הוא לפי ה-hash, ולכן זה עובד בכל אחסון סטטי בלי הגדרות שרת, וכפתורי "הקודם" ו"הבא" של הדפדפן עובדים.

## מבנה

```
index.html          מעטפת: הגופנים, הקנבס של הרקע, פס ההתקדמות, כפתור הצליל
css/styles.css      מערכת העיצוב: זכוכית, כפתורים, כניסת תוכן מדורגת, עולם צבעוני לכל עמוד
js/main.js          הראוטר: מעברים, כפתורי חזרה/הבא ותג הפרק (נבנים מהסדר), מקלדת
js/pages/*.js       עמוד לכל קובץ
js/pages/index.js   סדר העמודים
js/lib/             ambient (רקע), audio (סאונד), fx (ניצוצות וקונפטי), progress (גילויים),
                    marble-sprite (גולות), sim (פיזיקה), molecule3d (צורונים תלת־ממדיים),
                    canvas (קנבס חד בכל מסך וגרירה), icons, page-context
```

### עמוד חדש

עמוד הוא מודול שמייצא:

```js
export const slug = 'my-page';               // הכתובת: #/my-page
export const title = 'כותרת';
export const chapter = 'שם קצר לתג הפרק';      // התג "פרק N · שם" נוצר אוטומטית
export const icon = 'sparkle';               // שם אייקון מ-js/lib/icons.js
export const nextLabel = 'ממשיכים';           // הטקסט על כפתור "הבא"
export const sectionClass = 'theme-my-page'; // עולם הצבעים (מוגדר ב-css/styles.css)
export const html = `...`;                   // תוכן העמוד, בלי כפתורי חזרה/הבא ובלי תג פרק
export function init(page) { ... }           // אופציונלי: מופעל כשהעמוד עולה
export const reinitOnResize = true;          // אופציונלי: init חוזר אחרי שינוי גודל מסך
export const nav = false;                    // אופציונלי: עמוד עם כפתורים משלו
```

לאחר מכן מוסיפים אותו ל-`js/pages/index.js` במקום הרצוי בסדר.

בתוך `init(page)`:

- `page.frame(...)` לאנימציות, `page.timeout(...)` לטיימרים, `{ signal: page.signal }` להאזנות. הכול מתנקה ביציאה מהעמוד.
- `fitCanvas(canvas)` (מ-`lib/canvas.js`) נותן קנבס חד בכל מסך, ומצייר ב-CSS pixels.
- `discover('id')` (מ-`lib/progress.js`) רושם גילוי חדש, ו-`page.ready()` גורם לכפתור "הבא" להאיר.
- תגית `<p class="insight">` נחשפת עם `.classList.add('show')` כשהאורח גילה את מה שהעמוד מלמד.

## הרצה מקומית

המודולים של JavaScript לא נטענים מ-`file://`, לכן צריך שרת סטטי:

```bash
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000/`.
